# Universal Design Final Project — Accessible Website Redesign
This repository contains the final implementation work for our Universal Design course project, focused on redesigning and recoding key components of the City of Lafayette Communications Department website. Our goal was to improve accessibility, usability, and structural clarity following WCAG 2.1 AA guidelines and heuristic evaluation best practices.

## The project includes:
### Overview
- Evaluation of accessibility and usability issues identified through automated (WAVE, NVDA) and manual audits.
- Redesign of two core pages using wireframes, improved information hierarchy, and reorganized navigation.
- A new site map reflecting a simplified, more intuitive structure.
- Recoding and posting of six fully corrected components, each replacing inaccessible or non-compliant elements from the original site.

### Included Components
- The repository contains standalone HTML/CSS files demonstrating corrected, accessible versions of:
- Keyboard-friendly navigation with corrected tab order (WCAG 2.4.3)
- Rewritten semantic heading structure (WCAG 1.3.1)
- Accessible alt text patterns for decorative and informative images (WCAG 1.1.1)
- High-contrast focus indicators for keyboard users (WCAG 2.4.7, 1.4.3)
- Descriptive and non-redundant link text (WCAG 2.4.4)
- Corrected ARIA labeling and skip-to-content functions (WCAG 2.4.1, 4.1.2)

Each component has been recoded to function independently in a browser and demonstrates real, accessible markup that adheres to universal design principles.

### Additional Project Artifacts
- Figma wireframes for redesigned homepage and City Council subpage.
- Three-level site map illustrating improved structure and reduced redundancy.
- Heuristic Evaluation Report (Draft One) and revision summary (Draft Two).
- Persona profile and cognitive walkthrough documenting user experience considerations.

## Goal
The redesign aims to ensure that community members—including those with visual, cognitive, or motor impairments—can reliably access city information, navigate the site with ease, and interact with content without barriers.
